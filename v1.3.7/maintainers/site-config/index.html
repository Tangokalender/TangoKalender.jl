site.toml

Every city's settings live in site.toml at the root of its data repository. The commands read it from the current directory (or --site=FILE), and a wrong value stops the build with a message naming the key.

slug = "oslo"
name = "Tangokalender | Oslo"
city = "Oslo"
site_url = "https://tango.oslo.no"
repo_url = "https://github.com/Tangokalender/tangokalender.github.io"
og_image = "assets/og-image.png"

[map]
center = [59.9139, 10.7522]
zoom = 12

[geocode]
countrycodes = "no"

Keys

The table is generated from the schema, schema/site.schema.json.

using TangoKalender, JSON, Markdown
s=JSON.parsefile(TangoKalender.SITE_SCHEMA_FILE); req=Set(s["required"])
rows=String[]
row(k,p)=push!(rows,"| `$k` | $(k in req ? "yes" : "") | $(replace(get(p,"description",""),"|"=>"\\|")) |")
for (k,p) in s["properties"]
 if k in ("map","geocode")
  for (k2,p2) in p["properties"]; row("$k.$k2",p2); end
 elseif k!="texts"
  row(k,p)
 end
end
row("texts.nb / .en / .es",s["properties"]["texts"])
Markdown.parse("| Key | Required | Meaning |\n|:--|:--|:--|\n"*join(rows,"\n"))
KeyRequiredMeaning
slugyesShort id of the site, e.g. oslo.
nameyesSite name in titles, feeds and previews, e.g. «Tangokalender | Oslo».
cityyesThe city: default venue city, texts and geocoding.
site_urlyesWhere the site is published (may include a path), e.g. https://tango.oslo.no or https://example.github.io/bergen.
repo_urlyesThe data repo with the issue forms.
og_imageLink-preview image (1200×630 PNG), relative to site.toml. Default: the package's generic image.
map.center[lat, lon] shown when no event has a position.
map.zoom
geocode.countrycodesNominatim countrycodes, e.g. no.
geocode.viewboxNominatim viewbox lon1,lat1,lon2,lat2 to prefer results in the city.
texts.nb / .en / .esUI strings that replace the package's defaults, per language, keyed like src/i18n.jl (_T), e.g. site.tagline.

Changing texts

Any text on the site can be replaced per language under [texts.nb], [texts.en] or [texts.es], keyed like the package's strings in src/i18n.jl. {city} and {CITY} (upper case) are replaced by the city:

[texts.nb]
"site.subtitle" = "Milongaer, practicaer og kurs i {city} og omegn"
[texts.en]
"site.subtitle" = "Milongas, practicas and classes in and around {city}"

Norway only

All sites share Norwegian time (Europe/Oslo), prices in kroner and the Norwegian issue forms, so a city outside Norway would need changes in the package.
